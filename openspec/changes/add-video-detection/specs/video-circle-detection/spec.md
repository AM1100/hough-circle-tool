# Spec Delta
## Purpose
让接手开发者在现有本机图片霍夫圆检测工具之上增加离线视频导入能力，逐帧记录圆检测结果并保留无圆帧，输出可与原视频对照的标注画面和帧级数据，避免将图片功能完成状态误当成视频功能已经验收。
## ADDED Requirements
### Requirement: 本地视频导入与完整处理
工具 SHALL 在浏览器界面允许选择本地 MP4 和当前霍夫参数，离线处理全部可解码帧；视频不上传第三方。合法视频 MUST 保留原帧顺序与尺寸；输出使用输入的有效帧率。本首版不保留音频，不承诺实时速度。
#### Scenario: 导入正常短视频
- **WHEN** 用户选择可解码且帧率有效的 MP4，填写有效参数并运行
- **THEN** 所有输入帧按顺序被处理，输出帧数、宽高与输入一致且使用相同帧率
#### Scenario: 无效视频或帧率
- **WHEN** 输入不能打开、没有可解码帧或帧率非有限正数
- **THEN** 显示可理解的错误，不将失败任务呈现为已完成
### Requirement: 逐帧记录并导出
工具 SHALL 生成标注 MP4 和逐帧 JSONL。每行 MUST 包含从0开始的 frame_index、time_s、count、circles；circles 为圆心 x/y 和 radius 列表，无圆时 count=0 且 circles=[]，不能沿用旧帧结果。界面 SHALL 显示完成状态、处理帧数，并提供两个结果的下载入口。
#### Scenario: 有圆无圆再出现
- **WHEN** 视频依次包含有圆、无圆、再次有圆的阶段
- **THEN** JSONL 每帧都有一行，时间按帧号与有效帧率对应，无圆阶段输出空列表且标注画面不绘制旧圆
### Requirement: 图片功能兼容
视频功能 SHALL 保留已有图片导入、参数编辑、预览、PNG 导出、两组实拍图预设与 CLI。
#### Scenario: 原图片基线
- **WHEN** 按 README 复跑硬币和饼干盘图片预设及现有测试
- **THEN** 仍分别检测两个硬币外缘和一个盘沿，已有测试通过，输出 PNG 尺寸与原图一致
