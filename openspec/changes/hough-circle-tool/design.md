# Design
## Context
样例分别为 760×385 与 520×520，需检测整体外缘。使用 OpenCV 官方 HoughCircles 梯度法，先转灰度并做中值滤波。
## Goals / Non-Goals
目标是本地运行且无需额外桌面 GUI 系统库；不包含模型训练或云端处理。
## Decisions
- 使用标准库 ThreadingHTTPServer + 浏览器界面，绑定 127.0.0.1。相比 Tk，无需系统 tkinter 包，图片预览和导出直接使用浏览器能力。
- /api/detect 接受图片与参数，返回 PNG 与浮点圆坐标。服务不保存用户图片。
- 界面保留原始图片，每次从原图检测；参数修改后使旧结果失效。
- 样例预设限制半径范围，避免硬币内部花纹或饼干误检。不会硬编码检测圆坐标。
## Risks / Trade-offs
- 霍夫参数依赖图片尺寸与内容 → README 记录每张图的参数和适用限制。
- 超大图片消耗资源 → 限制请求体与图片像素总数。
- 本地服务入口 → 仅监听回环地址，拒绝非本地 Origin 的 POST。
