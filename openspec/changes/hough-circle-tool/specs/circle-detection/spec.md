# Spec Delta
## Purpose
为视觉组训练提供可重复验收的霍夫圆检测工具，允许用户导入自己的图片，调整检测参数并查看圆心半径和标注预览，再将完整分辨率的结果保存为图片用于交流与提交作业。
## ADDED Requirements
### Requirement: 导入与调参预览
工具 SHALL 支持导入 JPG/JPEG/PNG，编辑 dp、圆心最小距离、边缘阈值、累加器阈值、半径范围和中值滤波核，显示原图与检测标注、圆数和每个圆的坐标半径。无效图片或参数 SHALL 给出可理解错误，未检测到圆 SHALL 显示零个圆。
#### Scenario: 导入图片运行
- **WHEN** 用户导入有效图片、设置参数并点击检测
- **THEN** 显示完整图片的圆标注和检测数量
#### Scenario: 输入错误
- **WHEN** 图片不能解码或参数无效
- **THEN** 显示错误且服务继续可用
### Requirement: 导出与复现
工具 SHALL 将当前检测结果导出为与原图同尺寸的 PNG，并提供可复现的样例参数。
#### Scenario: 两张指定照片
- **WHEN** 分别加载硬币与饼干盘样例并应用对应预设
- **THEN** 硬币图标出两个硬币外缘，饼干盘图标出一个盘沿，并可导出 PNG
#### Scenario: 导出后重新调参
- **WHEN** 参数改变后尚未重新检测
- **THEN** 禁止导出过时结果，提示重新检测
