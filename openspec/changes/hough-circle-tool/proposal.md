# Proposal
## Why
培训任务三要求可交互的霍夫圆检测工具，并用指定硬币和饼干盘实拍图片验证。
## What Changes
- 本地图形界面支持图片导入、参数编辑、结果预览和 PNG 标注图导出。
- 提供两组验收预设、命令行批量复现入口和实际结果图。
- 记录无效输入提示和检测结果坐标。
## Capabilities
### New Capabilities
- `circle-detection`: 从图片检测圆并预览与导出。
### Modified Capabilities
无。
## Impact
新增 Python/OpenCV 项目、浏览器界面、测试、样例与说明。
